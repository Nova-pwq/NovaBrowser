NovaBrowser
1) Встановіть Node.js (https://nodejs.org)
2) У папці проєкту:  npm install
3) Запуск:           npm start
4) Інсталятор .exe:  npm run dist   (результат у папці dist)

5) Простори: кнопки 1 / 2 / … ліворуч від вкладок — у кожного своя сесія (інший акаунт на тому ж сайті). Правий клік по вкладці — перемістити в інший простір. Простір 2 — зелений.

6) Authenticator: меню (⋮) → Authenticator. Додайте секретний ключ або посилання otpauth:// — браузер показує 6-значні коди, які змінюються кожні 30 с (як Google/Microsoft Authenticator). «Вставити» кладе код у поле 2FA на сторінці; коли сторінка просить код, зверху з'являється пропозиція заповнити його. Ключі шифруються засобами ОС.

7) Кнопка з 9 крапками (праворуч у панелі): Gmail, Outlook, Yahoo, Proton, iCloud, Ukr.net. Можна закріпити будь-який сайт або поточну сторінку; × на плитці — прибрати. Відкривається в поточному просторі.
